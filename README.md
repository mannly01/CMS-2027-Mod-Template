# CMS 2027 Mod Template - 1.1.0
A Visual Studio 2022+ Template for CMS 2027 and MelonLoader 0.7.3.

## Features
* Quickly start a new mod with just a few clicks
* Includes a default configuration file skeleton

## Installation
* Have Visual Studio 2022+ installed
* Have Car Mechanic Simulator 2026 with MelonLoader 0.7.3 installed
* Download .zip from [Releases](https://github.com/mannly01/CMS-2027-Mod-Template/releases/latest) page
* Copy .zip to `Documents\Visual Studio 2022\Templates\ProjectTemplates`
* Start a new Solution, search for 'CMS' and select the Template
